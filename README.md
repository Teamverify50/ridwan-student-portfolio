# Ridwan — Student Portfolio

A responsive student portfolio built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — page content and sections
- `style.css` — responsive blue-and-white styling
- `script.js` — mobile navigation and current year
- `assets/ridwan-workspace.jpg` — supplied workspace image

## Preview locally
Open `index.html` in a browser.

## Publish free with GitHub Pages
1. Sign in to GitHub and create a **new public repository** (for example, `ridwan-student-portfolio`).
2. Upload all files and folders from this project. Keep `index.html` in the repository root.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then click **Save**.
6. Wait a minute or two. GitHub will show the live website address in the Pages section.

## Before publishing
- Replace `hello@example.com` in `index.html` with the student's real email address.
- Add real project links and update the skills section as appropriate.
- The supplied image shows a person working at a desk from behind, not a face portrait. It is currently used as a workspace/hero image. Replace it with a headshot if a personal profile portrait is preferred.
